# 游戏音效与背景音触发清单

整理日期：2026-10-29。依据当前界面、规则引擎和五个已接入的剧本整理，供下一步选素材、制作声音和接入触发使用。本轮只整理需求。

2026-10-30 更新：第一批 P0 已接入，最终合并为 28 组短音效和 4 条循环。本文保留原始需求与后续优先级；实际实现与使用方式见 [声音接入说明](audio-implementation.md)。

## 现状与优先级

整理时 `app/page.jsx` 的“氛围音”开关只有持续的合成低频底音，以及作祟提示出现时的三次合成音；第一批实现已用独立音频系统替换。

- **P0：首批接入。** 玩家需要立即感知的行动、结果和阶段变化。
- **P1：完整体验。** 特殊房间、物品、联机及剧本专属反馈。
- **P2：氛围精修。** 卡牌剧情、房间细节和声音变体。

下面列的是“触发行为”，不要求每行制作一份独立音频。确认、成功、获得、恢复等反馈可以复用；具有明确物理来源的枪声、陷阱、电梯、玻璃、蒸汽等再做专属声音。

## 一、通用界面与回合

| 优先级 | 行为／触发时机 | 声音方向与复用 |
| --- | --- | --- |

| P0 | 探索正式开始 | 宅邸门轴或短入场音，衔接探索音乐 |
| P0 | 轮到本机负责的角色，或出现需要本机处理的投骰／选择／伤害请求 | 一次清晰的行动提示；同一请求不循环催促 |
| P1 | 结束角色行动 | 短确认音，可复用按钮确认；随后角色交接不再堆一层提示 |

| P1 | 经典剧本／旧狼人进入自动敌人阶段 | 短威胁提示；血月没有自动敌人阶段，不套用此触发 |
| P1 | 联机玩家加入／离开、开局、连接中断／恢复 | 各用简短状态提示；只在状态改变时响，轮询和重试不重复响 |

| 优先级 | 行为／触发时机 | 声音方向与复用 |
| --- | --- | --- |
| P0 | 点击未探索门口，成功抽出新房间并出现预览 | 老门开启＋板块抽出，可组合成一段探索音 |
| P1 | 旋转房间、预览吸附到合法位置 | 很轻的木片拨动／卡位声；只在朝向或吸附位置实际改变时响 |
| P0 | 确认房间放置、板块实际落位 | 木质落板；预览拖动不触发落板声 |
| P0 | 人物沿相通的门实际移动到另一房间 | 一小段脚步；与棋子移动同步，每段路径一次 |
| P1 | 人物通过楼梯、暗梯跨层 | 楼梯脚步变体；单纯切换地图楼层标签不响 |
| P1 | 首次发现地下阶梯／打通回程暗梯 | 暗门开启或空间展开音，强调新通路已建立 |
| P1 | 神秘电梯启动、实际搬移、停靠 | 机械启动→运行→刹停；原位停靠只播短启停，不播放跨层移动声 |
| P1 | 电梯发生冲击 | 金属撞击；乘员后续各自分配伤害时不重复播放整段电梯冲击 |
| P1 | 首次坍塌检定失败，楼板断裂 | 木板开裂；检定成功不播放坍塌声 |
| P1 | 从坍塌房间坠落／主动跳下并落地 | 短下坠＋落地；复用旧落点时不重播“首次楼板断裂” |
| P0 | 自动敌人沿路径逐房追击 | 较重脚步或爬行声，跟随现有移动帧；到达陷阱处立即截停 |
| P2 | 地面材质、人物／怪物类别不同 | 木地板、石地、湿地，以及狼人／幽影脚步变体 |

拖地图、滚轮缩放、悬停房间、回到人物、适配全图默认静音。这些动作频繁，不改变游戏世界。

| 优先级 | 行为／触发时机 | 声音方向与复用 |
| --- | --- | --- |
| P0 | 事件牌首次翻开 | 翻纸＋短悬疑音 |
| P0 | 物品牌首次翻开 | 翻纸＋克制的发现提示 |
| P0 | 预兆牌首次翻开 | 翻纸＋低频异响，与事件／物品保持可辨差异 |
| P1 | 正式收下物品／预兆，写入人物持有列表 | 很短的收纳音；若与翻牌紧邻可合并，不重复“发现” |
| P0 | 骰组开始投掷／自动投掷 | 按骰组播放滚骰声；不为每枚骰子叠完整音轨 |
| P0 | 骰子停稳，点数正式展示 | 一次落定声；关闭动画时使用短落定反馈 |
| P1 | 家族戒指重掷一枚合法骰子 | 短金属泛音＋单骰滚动／落定，保持原骰组窗口的连续性 |
| P0 | 属性／目标检定最终成功或失败 | 两种克制的结果音；等待重掷、庇护等反应结束后，以最终结果为准 |
| P0 | 作祟检定开始 | 短蓄势低音，叠在骰声下；因最高点数不足而跳过检定时不播放投骰或蓄势 |
| P1 | 作祟检定结束，实际未触发作祟 | 短释压尾音；不使用任务完成或胜利音 |
| P0 | 作祟正式降临，剧本与新目标揭示 | 一次强阶段转场音，接作祟音乐；替代现有简单合成提示 |
| P1 | 作祟中的初始叛变／阵营揭示 | 短异化音，可融入作祟转场；不与同一人的转化音重复 |
| P2 | 特定事件／预兆的故事首次展示 | 按内容附加短拟音，见下方；再次查看卡牌详情不重播剧情 |

P2 可先覆盖有明确声源的事件牌：墙后低语、腐朽地板、沉重铁门、楼上脚步、刺骨寒风、炉灰摩擦、油灯燃烧、手记翻页。密码和肖像可共用轻微异响；预兆先共享一套声音，咬痕可补暗处扑袭／撕咬。剧情低语无需制作可辨识的人声台词。

## 四、战斗、伤害与人物状态

| 优先级 | 行为／触发时机 | 声音方向与复用 |
| --- | --- | --- |
| P0 | 一次有效近战／撕咬对抗开始 | 挥击或扑袭短音；伤害反馈等待最终结算 |
| P0 | 近战命中、反击造成实际肉体伤害 | 一次肉体受击音；英雄受伤与旧式敌人扣 HP 都需覆盖 |
| P1 | 对抗平局、射击闪避、伤害全部抵消 | 短格挡／擦过音；不误播受伤声 |
| P0 | 实际承受精神伤害 | 低频冲击／耳鸣尾音，与肉体受击区分 |
| P0 | 非伤害来源使属性实际提升／下降 | 短上扬／下沉音；房间馈赠、预兆和事件复用 |
| P0 | 角色死亡、敌人被击败 | 人物用短终止音，敌人用消散／倒地；致胜击杀优先进入结局 |
| P1 | 主动休整、治疗／恢复实际生效 | 短呼吸或回稳音；多项属性恢复合并一次 |
| P1 | 获得负面状态、状态加重、负面状态被清除／降级 | 压迫／加深／净化三类反馈；只有剩余轮数普通变化不逐次响 |
| P1 | 庇护／保护实际阻止伤害或状态 | 短护佑音；与纯粹的检定成功音合并或替换 |

伤害分配的加减按钮只使用轻触点；玩家确认后，实际扣减才播放受伤反馈。一次伤害导致力量、速度同时下降时，不再叠两次属性下降音。

## 六、五个剧本的专属触发

以下专属音优先级为 P1；目标进度、胜负的通用反馈属于 P0。专属音可以替换通用音，避免同一结果连响两遍。

| 剧本 | 需要声音的实际变化 | 声音方向 |
| --- | --- | --- |
| 第十三声钟响 | 守钟人揭示；祭坛封印成功；钟声幽影生成；倒计时进入最后阶段；超时结局 | 钟摆、低钟、仪式封合、幽影凝聚；最终钟声只在对应结局出现 |
| 镜中来客 | 调查古镜；空镜获得银屑；真身现形；击败镜魇 | 玻璃摩擦、银屑轻响、玻璃裂开／倒影走出、碎裂消散 |
| 深水之下 | 拾取保险丝；修复发电机、电力恢复；逃生实际完成；超时结局 | 金属拾取、发电机启动／电闸、开门逃生、黑水吞没 |
| 月光照进来的时候（旧狼人） | 狼王揭示；狼毒感染；治疗成功／获得净血保护；感染到期转化；封窗；月印进度增加／净化完成；入口解咒；月光恢复 | 狼嚎、低脉冲、净化、异化、钉板、仪式、回稳；进度增加与整处完成分强弱 |
| 血月之夜 | 初始狼人揭示；满月／血月到来；感染Ⅰ／Ⅱ实际获得或升级；抵抗检定失败转化；嗜血实际恢复；追猎额外移动实际消费；普通伤害触发不死虚弱；银弹命中存活后永久削弱 | 月相升压、感染加深、异化、短吸收恢复、急促脚步、不死低吼、银质灼烧／锁定 |

补充约束：

- 旧狼人按感染倒计时转化；血月按感染等级与抵抗检定处理，不能共用一套触发条件。
- 旧狼人封窗时播放钉板，月光效果随之解除；血月的满月／血月是全局月相推进。
- 血月无轮数上限，不能加入“时间耗尽”警告。旧剧本的末期警告建议在实际剩余 3 轮时首次响一次，不逐秒催促。
- 嗜血按本次恢复流程合并播放，不随每次力量／速度分配按钮连续响；追猎音只在额外移动实际消费时附加。
- 感染、庇护、狼化、永久削弱必须等各自反应与伤害流程结束后播放对应结果，不能由攻击命中直接推断。

## 七、目标与结局

| 优先级 | 行为／触发时机 | 声音方向 |
| --- | --- | --- |
| P0 | 目标取得阶段进度：保险丝、祭坛、月印等 | 一次明确但克制的进度提示；有专属拟音时合并 |
| P0 | 一处目标彻底完成／关键设施恢复 | 稍强的完成音；不能误用整局胜利音 |
| P0 | 游戏正式结束：本方胜利／失败 | 各一段结局短乐句，压低或淡出当前背景音乐 |

## 八、背景音乐与环境底音

音乐负责局势，环境声负责空间，两者独立控制音量。建议无歌词、稀疏配器、可循环，避免持续高强度鼓点影响读卡和思考。

| 类型 | 适用状态 | 内容与切换 |
| --- | --- | --- |
| BGM · P0 | 主菜单、角色选择、联机等待大厅 | 同一首低密度宅邸主题，可共用 |
| BGM · P0 | 探索阶段 | 低张力悬疑循环；首次探索开始后淡入 |
| BGM · P0 | 作祟阶段通用底乐 | 作祟转场后接入，压迫感高于探索；首版五个剧本可共享 |
| BGM · P1 | 第十三声钟响 | 在通用作祟底乐上加入钟摆／钟声主题 |
| BGM · P1 | 镜中来客 | 冷色玻璃泛音、倒放音色 |
| BGM · P1 | 深水之下 | 水下低频与缓慢上升的压力；电力恢复后稍作变化 |
| BGM · P1 | 旧狼人 | 稀疏脉冲与远处狼嚎，保留封窗、治疗和仪式音的空间 |
| BGM · P1 | 血月之夜 | 初醒→满月→血月逐层增加张力；月相变化不必重启整首曲子 |
| 环境 · P0 | 宅邸通用空间 | 轻风、远处木结构声、室内空响，长时间低音量循环 |
| 环境 · P1 | 一楼／二楼／地下室 | 一楼风与建筑声；二楼屋顶风、木梁；地下室滴水、管道低鸣，随当前行动人物实际所在楼层变化 |
| 环境 · P2 | 特殊空间 | 锅炉／蒸汽、实验室器皿、礼拜堂回响、钟表室滴答、音乐室少量走调琴音等，按需叠加 |

每次短战斗先用动作与结果音强调，不频繁切换整首音乐；结局先播放胜负短乐句，完整结局循环可放到后续。背景空间偶发声只用于氛围，避免使用会被误认成真实攻击、真实移动或可交互目标的强提示。

## 九、播放顺序与复用原则

1. **规则结果与画面对应。** 短按钮音可以立即响应；游戏结果以实际确认的状态变化为准，跟随现有移动、掷骰、播报和伤害流程展示。音频加载或播放结束不阻塞规则推进。
2. **同一次结果只提示一次。** 按事件／请求编号和流程来源去重。伤害、属性下降、文字播报、手记记录指向同一结果时，共用一次反馈；恢复同理。
3. **恢复不重播历史。** 继续存档、刷新、重连以最新已知事件建立基线；可以恢复音乐和当前环境，历史脚步、枪声、翻牌与作祟转场不补播。
4. **跳过动画同步截断。** 跳过敌人移动时停止剩余脚步；骰子动画关闭时使用短反馈，不让声音继续翻滚。
5. **提示有主次。** 结局、作祟和重大揭示优先；播放时压低音乐与环境。普通事件音控制同时发声数量，避免连锁结算轰鸣。
6. **声音遵守可见性。** 本地控件只在本机响；公共行动可在可见客户端播放。私人请求只提醒对应座位，隐藏陷阱的布置、敌方私有属性／物品不能通过声音泄露。
7. **照顾长局。** 高频脚步／骰声准备少量变体；悬停、拖动、倒计时普通变化默认静音。先提供总静音、音乐、环境、音效音量，并保留本机偏好；浏览器音频在用户手势后解锁。

## 十、建议接入批次与代码入口

**第一批：让主要行动与结果可听见。** 覆盖 P0：探索与移动、放房、三类翻牌、投骰与落定、检定结果、作祟、战斗与伤害、属性恢复／变化、回合提醒、目标进度、死亡和结局；背景先用大厅／探索／作祟三套循环与通用宅邸环境。按复用设计，先准备约 25–30 组短音效即可覆盖主要流程，具体数量在选材时合并确认。

**第二批：补齐已实现机制。** 特殊房间、物品、枪械、感染／治疗／转化、月相、嗜血、追猎、不死虚弱、五个剧本专属反馈，以及联机状态音。
