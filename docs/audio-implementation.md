## 试玩

右上角“设置与菜单” → 点击喇叭开启声音 → “音量”调节四路音量。点击“试听提示音”可以检查输出。默认关闭，默认音量为总音量 80%、背景音乐 30%、宅邸环境 25%、行动音效 75%。开关和音量保存在当前浏览器。

浏览器需要一次点击或按键才能启动声音。刷新后保留开启偏好，在第一次交互时恢复播放；页面切到后台会静音，回到前台后恢复当前背景。声音加载失败会显示重试提示，可关闭再开启声音重试。

开发版、局域网／远程网页版和离线 HTML 共用同一套播放逻辑。执行 `npm run build:portable` 会把全部音频嵌入 `outputs/预兆之屋-demo.html`，离线音频无需网络。声音偏好属于设备，不随联机房间广播。

## 28 组短音效

| 场景       | 资源 ID                                    | 实际触发                                                   |
| ---------- | ------------------------------------------ | ---------------------------------------------------------- |
| 探索与放房 | `explore`、`tilePlace`                     | 成功抽房并打开预览；房间正式加入地图                       |
| 移动       | `step`、`stairs`、`enemyStep`              | 人物和敌人的逐房移动帧；跨楼层复用楼梯脚步                 |
| 三类翻牌   | `cardEvent`、`cardItem`、`cardOmen`        | 对应卡牌首次成为当前展示内容                               |
| 投骰       | `diceRoll`、`diceStop`                     | 新骰组开始翻滚；750ms 后落定。关闭动画时只响落定           |
| 检定       | `checkSuccess`、`checkFailure`             | 最终检定成功／失败，包括失败后直接进入伤害分配的事件       |
| 作祟       | `hauntRoll`、`haunt`                       | 作祟投骰请求；作祟说明正式展示。不可能触发而跳过的检定不响 |
| 战斗与伤害 | `attack`、`hit`、`mentalHit`               | 对抗请求开始；肉体／精神伤害实际结算。分配预览不响受击     |
| 属性       | `traitUp`、`traitDown`、`heal`             | 非伤害属性变化；休整和恢复物品实际恢复属性                 |
| 回合       | `turn`、`round`                            | 本机负责角色的回合提示；新一轮提示                         |
| 目标       | `objective`、`objectiveDone`               | 保险丝、银屑、祭坛、月印等进度增加；设施启动或房间目标完成 |
| 死亡与结局 | `death`、`enemyDeath`、`victory`、`defeat` | 人物死亡、敌人移除、本方胜负确定。结局优先于同帧伤害音     |

联机按玩家可见状态触发，隐藏事件不参与播放。胜负音按本机所控阵营判断；同机控制多个阵营或没有角色的旁观者使用中性的完成音。

## 背景与混音

- `lobby`：大厅低密度钟声。
- `exploreMusic`：探索低音悬疑循环。
- `hauntMusic`：作祟脉冲循环，在作祟说明实际展示时切换。
- `manor`：通用宅邸低频／风声环境层，与前三者叠加。

每条循环长 24 秒；跨阶段淡出约 1.5 秒并淡入新背景。结局停止背景，由结局短乐句收束。作祟、死亡和胜负短音压低音乐，最多同时播放 6 个短音。同一次更新内相同语义合并，连续通知短暂错开。

音效与地图／骰子展示同步，不改变游戏随机数或规则。刷新、读档、回到测试点和联机重连会重新建立事件基线，避免重放旧行动；离开掷骰请求、关闭动画和静音会取消已排队的对应声音。

## 素材与替换

12 组拟音来自 Kenney 官方 CC0 音效包，保留原始 OGG 与许可；16 组结果提示和全部循环由项目脚本原创合成。完整来源和处理方式见 [音频素材鸣谢](../public/audio/CREDITS.md)。全部 32 个运行时文件为单声道、24kHz、16bit WAV，合计小于 7MiB。

| 文件                                               | 职责                                               |
| -------------------------------------------------- | -------------------------------------------------- |
| `lib/audio-assets.mjs`                             | 共享音频清单、默认音量与输入校验                   |
| `lib/audio-events.mjs`                             | 从可见游戏状态和展示帧产生语义音效，去重及恢复基线 |
| `lib/audio-player.mjs`                             | Web Audio 加载、混音、循环切换、并发限制与取消     |
| `app/game-audio.jsx`、`app/audio.css`              | React 生命周期、偏好保存与声音设置面板             |
| `public/audio/`                                    | 网页直接使用的 WAV 和素材鸣谢                      |
| `scripts/audio-source/`、`scripts/build-audio.mjs` | 原始素材与可重复生成脚本                           |
| `scripts/build-portable.mjs`                       | 离线版嵌入音频，不再请求外部文件                   |

替换素材时保持资源 ID 和文件路径即可；调整清单后重新构建。要重新生成当前声音，安装 FFmpeg 并运行 `node scripts/build-audio.mjs`。普通开发、构建和离线打包使用已保存的 WAV，不需要 FFmpeg。新素材应同时更新鸣谢与来源记录。

## 验证

`node --test tests/audio.test.mjs` 检查真实 WAV、响度与循环接缝、真实探索／抽牌／投骰／检定流程、伤害去重、隐藏事件、阵营结局、五个剧本的定向测试入口，以及播放器静音／取消／离线解码。完整回归使用 `npm test`；生产与离线构建使用 `npm run build:portable`。

声音风格使用首批基础版本；房间、枪械、物品和剧本专属拟音及随机变体仍按原清单列为后续工作。
