# 第三批：空间与故事音效

2026-10-31。第三批新增 22 组短音效／变体和 14 条循环；三批累计 86 组短音效、18 条循环，共 104 个本地 WAV。继续沿用声音开关、四路音量和离线内嵌，无需外部音频服务。

## 空间与音乐

环境跟随当前行动人物实际所在房间；移动期间跟随展示帧。切换地图楼层标签、拖动或缩放地图不会切换声音。联机只能使用投影中可见的位置，位置缺失时回退到通用宅邸底音。

| 层次 | 内容 |
| --- | --- |
| 三层空间 | 一楼建筑低鸣、二楼屋顶风、地下室管道低频与稀疏滴水；替换通用底音而非额外全音量叠加 |
| 特殊房间 | 锅炉房低鸣、实验室器皿、祈祷室／祭室回响、钟表室滴答、音乐室稀疏失谐音符 |
| 蒸汽 | 只在蒸汽已生效且当前人物处于其影响房间时叠加低音量持续层；离开、过期或结局淡出 |
| 剧本主题 | 作祟通用底乐叠加钟声、玻璃、水下压力、狼人脉冲、血月脉冲五个主题层；电力恢复降低深水主题张力 |
| 血月推进 | 初醒、满月、血月逐步提高同一主题层音量，保持循环播放位置，不重启整首音乐 |

原有四条循环为 24 秒，新层为 12 秒循环。常驻层采用保守音量，切换淡出约 1.5 秒；主题层归“背景音乐”，空间与房间层归“宅邸环境”。作祟、死亡和结局同时压低两类背景；结局停止所有背景层。

## 故事与变体

十组剧情拟音覆盖墙后低语、腐朽地板、铁门、楼上脚步、寒风、炉灰、灯火、手记、密码／肖像异响和咬痕。低语采用无可辨台词的合成气声。剧情音在卡牌首次成为当前展示内容后延迟 240ms 轻声播放，翻页或关闭卡牌即取消；重新查看详情、刷新和继续存档不会补播。

十二个短音变体扩展木地板、石地、湿地、狼人重步、幽影轻步和滚骰。湿地按井间、洗衣房、花房／庭院映射，地下室其余空间采用石地，其余默认木地板。未知敌人回退幽影脚步；狼人阵营人物使用狼人脚步。楼梯、坠落仍使用对应动作声。

播放器使用私有伪随机序列，避免同组连续选中同一变体；不读取或改变游戏随机数。变体基于已授权 Kenney 拟音重采样／滤波，剧情和环境为原创程序合成，来源记录见 `public/audio/CREDITS.md`。这仍是可替换的合成声音版本，后续可按同名路径换为更自然的录音。

## 维护与验证

- `lib/audio-spatial.mjs`：楼层、房间、剧本混音层及剧情／变体映射。
- `lib/audio-player.mjs`：同名循环保留播放位置，仅渐变音量；变体选择、背景压低及取消。
- `scripts/audio-spatial-recipes.mjs`：原创空间与剧情配方，以及派生拟音配方。
- `tests/audio-spatial.test.mjs`：实际位置与地图标签分离、蒸汽范围、血月增益不重启、剧情去重、变体轮换、后台恢复和结局清场。

`node scripts/build-audio.mjs` 重建素材（需要 FFmpeg）；`npm test` 运行回归；`npm run build:portable` 构建网页与离线版。所有 104 个 WAV 均检查格式、非静音、峰值、循环接缝及总大小。
