# 第二批：机制与剧本音效

第三批已补充下文当时待办的持续蒸汽、剧本主题层、三层空间和剧情拟音，最新实现见 [第三批说明](audio-phase-three.md)。

2026-10-31。新增 36 组短音效，总计 64 组短音效与原有 4 条背景／环境循环。第二批采用项目原创程序合成拟音，无新增外部授权依赖；更自然的录音素材可按同名资源替换。声音开关和四路音量沿用第一批设置。

## 已接入

| 范围       | 触发与声音                                                                                                                          |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 特殊房间   | 电梯启动／搬移与冲击、首次失败的楼板开裂、实际坠落、楼梯通路建立、放房预览改变时的轻触点                                            |
| 物品       | 正式获得、交付、放下、拾取、使用；药品饮用、包扎、选定制药产物、成功熔铸；失败或仍在选择时不响获得音                                |
| 枪械       | 装填／卸弹共用枪机声；普通／银弹射击使用不同尾音；选择目标、非法命令和历史恢复不响枪                                                |
| 机关       | 可见陷阱成功布置；人物陷阱按地图触发帧合拢，自动敌人按陷阱播报合拢；蒸汽开阀与实际喷发分开，到期使用泄压尾音                        |
| 检定与保护 | 戒指重掷附金属泛音及骰声；未作祟使用释压音；对抗未伤、闪避、伤害抵消与徽章保护使用护佑反馈                                          |
| 状态       | 负面状态新增／升级／清除，感染Ⅰ／Ⅱ、转化、月相、嗜血恢复、追猎、不死虚弱、银弹永久削弱                                              |
| 五个剧本   | 作祟揭示添加钟声／玻璃／机械／异化主题；祭坛、镜面、银屑、保险丝、发电机、封窗和月印完成采用对应反馈；敌人生成和旧剧本剩余 3 轮提醒 |
| 联机       | 玩家加入／离开、掉线／恢复、明确错误；按状态变化去重，不随轮询和重试重复播放                                                        |

状态只从玩家可见的事件和状态变化读取，不解析中文日志。血月不使用轮数上限警告。嗜血逐格分配不响恢复，等待最终恢复记录；普通倒计时减少、保护自然过期不响净化。转化会压过同批感染／清除提示，专属目标反馈替换通用完成音，结局仍拥有最高优先级。

通用界面点击／面板翻页、长蒸汽环境层、五个剧本独立背景循环和三层环境差异尚未在本批扩展；本批保留原有三套背景音乐与宅邸环境循环，蒸汽使用短拟音。后续空间与故事精修沿用原始清单第三批安排。

## 开发与验证

- `lib/audio-mechanisms.mjs`：机制反馈、替换优先级及联机状态观察器。
- `lib/audio-events.mjs`：与地图触发帧、重掷和第一批语义音效整合。
- `scripts/audio-mechanism-recipes.mjs`：36 个可重复合成配方，使用独立随机种子，不改变第一批音频。
- `lib/game-engine.mjs`：补充坍塌事件和对抗伤害量，规则结果与随机数算法不变。
- `tests/audio-mechanisms.test.mjs`：实际银弹操作、隐藏陷阱、制药／蒸汽时序、状态和嗜血去重、坍塌顺序、血月警告与联机重连。

重新生成：`node scripts/build-audio.mjs`（需 FFmpeg）。普通构建使用已生成 WAV，无需 FFmpeg。

验证：`npm test`；构建与离线打包：`npm run build:portable`。所有新素材由共享清单自动加入离线 HTML。
