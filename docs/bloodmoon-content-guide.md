# 血月房间、信物与陷阱开发指南

本阶段实现实验室、锅炉房、消毒杀菌室、家族戒指、圣者徽章及捕兽夹。原狼人《月光照进来的时候》的普通开局与规则保持原样；新内容进入独立资源池和定向测试，不自动混入旧房间牌堆或物品牌堆。

## 试玩入口

运行 `npm run dev`，打开终端给出的地址，选择「定向测试 → 狼人 → 血月房间与机关（独立测试）」。

- 首位角色位于实验室，携带戒指、徽章和捕兽夹；三个新房间与地下室平台连通。
- 在实验室尝试制药，投骰后可触发戒指；成功后选择未制备过的药剂。
- 戒指／徽章在实验室或新锅炉房可熔铸为银弹；失败保留材料。
- 进入新锅炉房开阀，结束自己的回合后观察相邻房间蒸汽标记；下一位角色进入或在其中开始回合时检定。
- 同伴位于消毒杀菌室，带感染Ⅱ测试标记，结束其回合可选择净化。
- 捕兽夹可从背包或行动栏布置。让旧狼人沿该房间追猎，可验证路径中途截停与陷阱销毁。徽章可在同室同伴受到旧狼毒感染时尝试庇护。

本场景仍借用旧狼人地图与敌人框架，地图上会同时存在旧锅炉房和新锅炉房；只有新房间具有蒸汽／熔铸动作。测试感染标记不自动升级或转化。选择或投骰期间刷新页面后，从「定向测试 → 继续测试局」恢复。

## 已确认规则

| 内容 | 当前行为 |
| --- | --- |
| 行动机会 | 制药、熔铸、开阀、布夹独立计次，不扣原有互动、攻击、休整机会。制药、开阀、布夹每人每轮一次；熔铸每件材料每轮一次。 |
| 实验室 | Knowledge 5+；成功选择一种未制备的药剂。每种整局最多成功制备一次，使用、丢弃或转移后仍不能重制。失败也扣尝试。 |
| 熔铸 | 实验室／新锅炉房 Knowledge 4+。戒指、徽章各可成功产出一发银弹，合计最多两发。成功销毁材料，失败保留，尝试记录跟随材料实例。 |
| 消毒杀菌室 | 在此结束自己的回合，选择一个可清除负面状态。有等级则降一级，第一级或无等级状态移除；每人整局一次。放弃不扣次数，不撤销历史属性变化。 |
| 家族戒指 | 每轮一次，仅选择持有者自己的骰组中一枚 0 或 2 点骰重掷；接受新结果，重新计算原检定。放弃不扣次数；交易、丢弃和拾取不刷新。对抗检定可选自己的攻击或防御骰，不能选对方骰组。 |
| 圣者徽章 | 持有者可为自己或同室友方进行 Sanity 4+；成功取消本次可清除负面状态获得／升级，失败照常获得。尝试即扣本轮次数，放弃不扣。多枚徽章按稳定来源顺序响应，成功后跳过其余。 |
| 蒸汽范围 | 开阀者结束本回合时生效，到其下次回合开始时消散。仅覆盖锅炉房旋转后双向门直接相连的相邻房间，不包括锅炉房自身、隔墙房间和楼梯／传送链接。 |
| 蒸汽检定 | 每次开启的蒸汽持续期间，每名角色在每个受影响房间首次进入或开始回合时分别进行 Speed 4+。失败受 1 点身体伤害、当前回合停止移动；重复进入同一房间不重复检定。不同蒸汽分别计时、分别检定，不改变视线。 |
| 捕兽夹 | 布置时从背包取出，友方可见且不会触发。首名敌方移动进入时销毁陷阱、受 2 点身体伤害并停止本回合移动；从已有陷阱的房间开始回合不会触发。可从中途经过的房间触发，不能越过陷阱继续走到路径终点。 |

现有敌人使用 HP，因此旧狼人的环境伤害扣 HP，蒸汽用敌人的速度掷骰；这是测试旧战斗模型的适配。未来可控新狼人应使用属性轨道分配身体伤害，并接入不死规则，不能照搬 HP 扣减。当前捕兽夹只停止移动，仍允许在触发房间内正常攻击。

同一房间的陷阱与蒸汽分别结算，停止移动不会免除已进入房间的其他环境效果。开阀者死亡或转化、无法再开始自己的回合时，其蒸汽在到期轮开始时清理。

## 开发边界与持久化

- `lib/content/bloodmoon-rooms.mjs` 与 `bloodmoon-items.mjs` 保存独立定义。`supply: 'bloodmoon'` 保证普通洗牌不增加牌数、不改变随机数调用顺序。素材室仍可查看新定义；定向场景明确注入资源。
- `lib/content/bloodmoon-mechanics.mjs` 提供行动、触发器、可序列化 Workflow 及内容结算。通过引擎传入投骰、日志、相邻门、环境伤害服务，不反向导入引擎。
- 人物 `bloodmoonActions` 记录对应动作使用轮次，`sterilizationUsed` 记录整局净化；物品实例 `state.ringRound`、`badgeRound`、`smeltRound` 随交易／丢弃保留。
- `game.bloodmoon.crafted`／`smelted` 是整局生产台账，不能从当前背包反推生产次数。成功结算与材料销毁／产出在同一权威命令内同步完成。
- `game.bloodmoon.steam` 保存每次蒸汽的来源、开启者、房间范围、到期轮次和已检定的角色／房间组合；房间 `traps` 保存陷阱实例、阵营和布置者。
- 联机投影在服务端移除敌方陷阱及其空字段，并隐藏布置日志与对立人物的动作记录；不能只用界面条件隐藏图标。
- 新状态的正常获得／升级使用 `status.gain`，它派发可暂停的 `BeforeStatusGain`，确认未取消后才写入状态。`status.add` 是初始化或已确认结算的底层操作，例如药剂增益、测试初始标记，不触发徽章。感染Ⅱ属性变化尚未接入；后续必须在确认状态实际获得后结算，不能在发出状态请求前先改属性。
- 含玩家选择的 `status.gain`／`bloodmoon.flow` 不得放入 `effect.atomic`；引擎会明确拒绝。支付与交互流程应分阶段提交，不能用原子批次隐藏异步副作用。
- 选择、检定、到期反应和环境伤害保存父流程续体。伤害未结算完，不提前恢复入场效果；反应恢复不会重走支付、伤害或生产步骤。

正常游戏使用 Workflow 执行模式。旧的直算模拟器继续服务旧剧本差分测试；新增反应式内容的完整验收以 Workflow 为准。

## 当前范围

本次没有注册完整《血月之夜》剧本。咬痕、新狼人玩家控制、月相、感染自动升级／转化、嗜血、不死与手枪射击尚未接入。银弹目前可制造、携带、交易和丢弃，没有装填／射击按钮。消毒室净化与新感染Ⅱ回合末检定的先后，需在感染流程接入时确认。

旧存档可继续使用；新内容存档需要所有客户端和主机一起更新。房间画面复用现有图案，未新增图片依赖。
