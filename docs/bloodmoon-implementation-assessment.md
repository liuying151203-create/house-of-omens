# 《血月之夜》卡牌试作与机制评估

依据：[狼人剧本设计](狼人剧本.md)。日期：2026-09-22。

原《月光照进来的时候》继续使用 `werewolf` 的原有规则。新设计作为独立 `bloodmoon` 剧本接入，不替换旧狼人、感染倒计时或胜利条件。卡牌、房间、可控狼人、枪械、不死、感染、嗜血及追猎之后，2026-10-10 已接通专用游戏集、咬痕正式触发和单机／联机开局。最新规则见 [血月卡牌与机关指南](bloodmoon-content-guide.md)，分项验收见[验收指南](bloodmoon-acceptance-guide.md)。

## 开发阶段（更新于2026-10-10）

本轮正式接入验证：完整 Node.js 测试365项通过，新增14项覆盖血月预设／缺卡校验、咬痕持有者、3～6人真实探索、联机正式开局／座位权限／持久化，以及首页和管理界面展示。相关代码静态检查与生产构建通过。本地 Worker 验证血月正式创建、预设默认剧本、普通探索开局、WebSocket同步、重启恢复及关闭新建后的续局；原有迁移和过期检查同样通过，未部署。构建仍有既有的大于500kB分块和 vinext 路由分类提示。

测试和构建首次在受限沙箱中遇到本机端口／原生依赖文件权限错误，沿用允许既有工具运行的权限环境后通过，未修改依赖或放宽规则。上一阶段351项测试及感染／嗜血／追猎的25项新增验证记录继续有效。

浏览器自动试玩未完成：本轮浏览器工具拒绝访问现有本地页面，报告 URL 访问策略阻止操作，未尝试绕过。人物面板、开局选项、缺卡提示和预设只读行为通过服务端渲染测试；实际动画、悬浮和点击体验仍需按试玩指南人工验收。

| 阶段 | 内容与依赖 | 验收标准 |
| --- | --- | --- |
| 1：咬痕攻防 | 本轮完成。独立预兆获得流程：虚拟力量 4 攻击 → 持有者力量防御 → 戒指反应及确认 → 身体伤害分配及伤害反应 → 作祟检定。 | 不生成地图敌人、不消耗角色主动攻击机会；平局／防御获胜无反击；完整差值不套用旧狼人的伤害上限；保存恢复、重复确认、联机权限和探索手记均有测试。 |

每阶段先开放独立测试，再接正式流程。血月专用预设单独提供，咬痕不混入经典或通用扩展牌池。所有继续、选择、投骰和伤害命令仍由权威引擎推进，展示动画不代替规则结算。不要把新狼人的属性轨道压成 HP，也不要在旧狼人分支上叠加新月相和感染规则。

当前咬痕采用“防御方胜出无反击、完整差值伤害”的解释；探索阶段沿用最低保留第1格。旧咬痕测试仍进入旧狼人剧本，新“咬痕 → 血月正式触发”测试进入血月。咬痕现可由游戏集选入，以 `scenarioOnly: 'bloodmoon'` 排除通用预设；血月定向探索必须先确定存活持有者，再作祟，不能以随机英雄兜底。

## 本轮可试玩的效果

| 卡牌 | 实现 |
| --- | --- |
| 咬痕 | 已有独立试玩入口，虚拟攻击方 4 枚骰，抽牌者以当前力量防御，完整差值身体伤害先分配后进入作祟流程；戒指只可选自己的防御骰 |
| 力量药剂 | 自己回合获得持续 1 回合的增益，力量轨道立即右移 2 格，最多到最右格；使用者下次回合开始时回退 1 格且不致死；使用后物品销毁 |
| 速度药剂 | 自己回合速度轨道右移 2 格，规则同上；不额外赠送当前回合移动点 |
| 神智药剂 | 自己回合理智轨道右移 2 格，规则同上 |
| 解药 | 选择自己或同室存活探险者，由使用者逐项选择最多两个可清除负面状态，确认后统一清除并消耗物品 |
| 家族戒指／圣者徽章 | 每轮一次的重掷／庇护，支持选择、放弃、存档恢复、实例计次；徽章可阻止状态升级 |
| 捕兽夹 | 独立布置机会、阵营隐私、敌方首次入场伤害与中途截停 |
| 实验室／锅炉房／消毒杀菌室 | 制药、熔铸、延迟生效的蒸汽、回合末净化；独立地图块，不覆盖旧房间 |

药剂不消耗攻击、互动、休整机会，可以携带、交付、丢弃和拾取。在轨道已满时仍允许按设计使用并消耗。解药可以只选择一个状态，也可以在确认前取消；联机选择超时默认取消，不消耗物品。清除感染不会回退历史属性变化，也不会改变阵营或复活角色。

三种药剂都会留下可见的增益状态，持续到使用者下次回合开始，期间覆盖其他角色和敌人的行动；同轮切换角色不会提前到期。到期移除对应状态，并从该属性的当前所在格回退 1 格，最低为第 1 格（骷髅前一格）。这不是恢复使用前的快照，也不是扣回完整的 2 格：例如第 3 格升至第 5 格，到期降至第 4 格；期间受伤降至第 1 格则不再下降。轨道封顶未获得完整提升时，到期仍按上述规则回退。增益不能被解药清除，存档恢复后只结算一次。速度药剂到期时会校正已经预分配的移动点，按回退后的速度开始新回合。

解药可选择同室存活、仍保留角色回合的人物，包括新可控狼人；试作暂不限制目标阵营，只清除可清除负面状态，不逆转阵营，也不解除银弹永久上限。旧版已经变成 HP 敌人的狼人没有这个目标入口。正式剧本是否限制友方目标仍可在后续设计中明确。

### 试玩步骤

```powershell
npm run dev
```

打开终端给出的网址，依次进入：

1. 首页「定向测试」。
2. 选择狼人《月光照进来的时候》。
3. 测试场景选择「血月卡牌效果（独立测试）」。
4. 开始后确认作祟说明，在首位角色背包使用三种药剂或解药。
5. 使用药剂后检查人物的增益状态提示；结束整轮并完成敌人阶段，在使用者下次回合开始时确认对应属性回退 1 格、增益消失。

测试场景借用旧版地图和战斗框架；说明中明确标注它不是新剧本。三张药剂和解药直接作为测试资源发放，经典游戏集不混入这些新物品；普通新局可选择通用扩展或自定义游戏集加入，且不限定狼人剧本，详见 [游戏集指南](game-sets-guide.md)。同室队友的感染Ⅱ、中毒和恐惧是解药测试标记，不会自动伤害、升级或转化。感染Ⅱ测试已预先移动属性，用于验证清除后不回退数值。

在解药选择过程中刷新页面后，通过「定向测试 → 继续测试局」恢复选择。需要重试时使用现有测试点／重置场景功能；测试存档与普通局分开。

## 代码边界

- `lib/content/bloodmoon-items.mjs`：首批独立资源定义。`supply: 'bloodmoon'` 阻止这些资源进入默认抽牌堆。
- `lib/content/item-abilities.mjs`：药剂属性提升和解药目标规则。
- `lib/content/triggers.mjs`：通过通用 `TurnStarting` 时机筛选当前角色到期的药剂状态，不依赖旧狼人的感染倒计时。
- `lib/content/item-actions.mjs`：保留原属性目标，同时支持独立 `targetHeroId`，没有将人物目标塞进 `trait`。
- `lib/content/cleanse-workflow.mjs`：可序列化的状态选择、确认、取消流程。
- `lib/status-rules.mjs`：可清除状态判定。已知感染、中毒、流血、恐惧和减速可清除；显式 `removable: false` 优先。其他状态必须同时声明 `negative: true` 和 `removable: true`，避免误删增益或永久削弱。
- `lib/game-engine.mjs`：注册流程与白名单 `status.cleanse` 效果，复用原子物品支付。确认时重新检查目标与状态实例；任一条件失效则不消费物品、不清除其他状态。

选择期间不提前改状态或扣物品。状态清除与使用标记、次数和物品销毁在同一原子批次提交。药剂的属性提升、增益添加和物品销毁同样原子提交；每个增益保存独立状态实例、来源物品实例、属性和到期轮次，到期只移除对应实例。存档仍是 v4；新增流程由当前版本代码识别，进行中的新卡牌存档不保证能由旧程序打开，联机客户端与主机应同时更新。此前试作版本已喝掉的药剂没有增益记录，不追溯补扣；请新开测试局验证新规则。

## 仍需明确的规则

下列规则尚未最终定案，正式入口继续沿用已说明的试作解释；已确认的行动次数、徽章升级和蒸汽首次规则一并记录。

1. **行动预算**：已确认制药、熔铸、布夹、开阀各自独立计次，不共用旧互动机会。枪械试作按“射击占唯一主动攻击、每支枪每回合装填一次且不占攻击、可卸下但不退还装填次数”实现，正式规则待确认。
2. **咬痕对抗**：攻击方 4 枚骰、抽牌者按力量防御已确认；攻击失败时是否仅无伤结束，以及是否允许反击伤害、是否绕过旧版单次伤害上限，仍需约定。
3. **状态升级**：已确认徽章可阻止感染Ⅰ升级Ⅱ。每次进入感染Ⅱ均移动属性。
4. **回合末顺序**：试作先净化，再判断是否需要感染Ⅱ检定，此解释尚待设计者确认。不死惩罚按下一次自己的回合开始生效，当前已开始的回合不受影响；尚未开始的下一次角色回合可以处于同一完整轮次。
5. **蒸汽首次**：已确认每次蒸汽持续期间，每人每个受影响房间分别检定一次。实现中不同角色开启的蒸汽分别记录，不互相刷新。
6. **射击与遮挡**：允许同室射击，携带枪和银弹即可直接射击；中间房间有存活角色或敌人就阻挡，不区分房间内位置。银弹暂仅对初始狼人开放；次级狼人及其他目标的银弹规则仍待确认。
7. **精神伤害与不死**：初始狼人 Sanity／Knowledge 进入骷髅格时死亡，英雄立即获胜。
8. **有限资源失效**：戒指或徽章丢失、材料持有者死亡、银弹无法取回时是否允许继续、回收或直接判负。资源不可用时英雄仍可尝试通过精神伤害击杀初始狼人，但对局节奏与资源回收规则仍需确定。

数值检查：两项身体位置都在第 4 格时，在不进入骷髅的前提下总共只能下降 `3 + 3 = 6` 格，所以 7 点银弹伤害已经必杀。第一发能够存活，需要命中前两项位置提供至少 7 格非致命下降空间。第二发必杀的推导成立，但不意味着每局都需要两发。
