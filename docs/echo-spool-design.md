# 回声线轴物品设计

记录日期：2026-10-28。状态：物品牌、系线和回返的基础流程已实现，仍需完善边界与联机验证。

已确认保留名称「回声线轴」，采用先设置房间标记、之后瞬移返回的机制。下列完整文案和规则为本轮补全方案；4步范围、一次性消耗、行动限制与交互细则尚待试玩验证，不视为已经逐项确认。

## 卡牌定位

回声线轴是一件需要提前布置的一次性空间工具。持有者可以先在关键房间留下退路，再深入岔路探索、前往机关或离开队友，之后瞬移返回。

首版作为通用物品设计，探索期和作祟期均可使用，不绑定剧本、不提供属性或检定加成。未来实现后建议加入通用扩展游戏集，经典游戏集不自动加入；血月专用牌池是否收录另行决定。

## 正式卡面文案

**名称：回声线轴**

**类型：物品 · 一次性**

**故事：**

> 你把线头系在门把手上。走远后，线轴里仍传来那个房间的声音。

**效果：**

> 自己的回合可在当前房间留下线头标记，每个线轴整局只能设置一次。
>
> 与标记房间的可通行距离为1～4步时，可消耗线轴，瞬移返回该房间。允许跨层，不消耗移动力、攻击、互动或休整机会。
>
> 瞬移不经过沿途房间，抵达时正常结算目的地的进入效果。已因预兆、休整或其他效果停止移动时不能回返。

**背包摘要：** 留下线头，之后消耗线轴，瞬移返回可通行距离4步内的标记房间。

## 使用规则

### 系线

1. 持有者在自己的可行动回合，选择「留下线头」，将标记设置在当前房间。不能替其他人物设置，也不能选择远处或未探索房间。
2. 设置不消耗线轴，不花移动力，不占攻击、互动或休整机会。已经停止移动时仍可系线，但当回合不能回返。
3. 每个线轴只能设置一次。设置后不能更换、收回或手动清除标记；取消设置确认不消耗这次机会。
4. 系线后可在同一回合回返，只要已经离开标记房间且满足使用条件。

### 回返

1. 使用者必须存活、持有该线轴，且正在自己的可行动回合；有待处理的卡牌、骰子、伤害或其他选择时，先完成原流程。
2. 线头已经设置，目标房间仍存在，且使用者不在目标房间。
3. 使用者未被效果标记为「停止移动」。移动力自然用完但未被停止移动时，仍可回返；人物无法移动的其他明确限制同样适用。
4. 当前所在房间到目标的最短可通行距离为1～4步。不要求剩余移动力足以走完这段距离，也不进行检定。
5. 确认后消耗线轴、移除线头标记，将使用者直接放到目标房间，再结算目的地的进入效果。目的地伤害、停步或死亡不会退还线轴。
6. 仅传送使用者及其随身物品。同室的其他人物、敌人和地面物品不会同行；任务物品原有的携带与移动限制继续适用。
7. 回返本身不停止移动，不恢复移动力，也不恢复任何行动机会。若抵达效果没有阻止行动，仍可使用原有剩余移动力和行动机会。

### 距离与瞬移

距离按房间之间的通路计算，每跨入一个房间计1步。门必须双向接通；允许使用已建立、当前方向可通行的楼梯、暗梯或坍塌通路。未探索位置、隔墙、未建立的连接，以及必须另行启动或投骰才能形成的通路不计入。

距离只检查现有连接和人物的通行限制，不试算沿途伤害或检定结果。沿途的捕兽夹、蒸汽、角色或敌人不会被实际经过，也不会触发其效果；它们本身不额外增加距离。首版不按直线距离或楼层高度计算范围。

目的地按一次特殊进入处理，正常响应适用的入场效果，包括敌方捕兽夹与蒸汽，并保留它们原有的阵营、次数和时点限制。返回已探索房间不会重复抽取其发现时的卡牌，不重新触发仅限首次发现的效果。回返不是普通相邻移动，目的地的门不必朝向使用者。

## 标记与物品归属

- 标记绑定线轴实例和房间身份，不绑定设置者或地图坐标。神秘电梯等房间搬移时，线头随房间移动；回返范围按使用当时的地图重算。
- 交易、丢弃、拾取和阵营变化不会重置设置次数。后续持有者可使用原标记，仍受自己的回合、通行和停止移动限制。
- 标记为所有玩家可见，显示设置者和对应线轴；它不是房间内可单独拾取、交易或破坏的物品。原设置者死亡不会单独清除标记，线轴的去向沿用现有物品处理规则。
- 线轴消耗或被销毁时清除标记；普通转移不清除。目标房间被移除时，标记失效，不能重新设置，也不自动退还或消耗线轴。
- 不可达或超过范围时保留线轴和标记。地图变化后恢复可达且距离合格，即可再次使用。

## 视觉方向

物品图标以旧木线轴和一缕松开的细线为主体，沿用古金色剪影。线头标记使用小线结，与物品图标保持关联，避免依赖长线绘制整条路径。

回返时线轴轻微收紧、人物短暂淡出，再在目标房间显现；不播放逐房移动。跨层后切到目的地楼层并定位人物，目的地入场效果在落位后展示。可辅以短促、逐渐靠近的回声；关闭动画或声音不影响规则结算。

## 平衡依据与试玩重点

4步是首轮试玩参数：需要事先选点，且只能使用一次，适合从岔路回到汇合点。与登山靴持续增加移动、咖啡临时增加移动力相比，线轴提供避开途中危险的回程能力，同时受固定目的地和当前连通距离约束。

优先观察三个问题：标记是否经常来不及使用；4步是否足以产生有意义的退路；跳过途中危险是否显著降低逃生或追猎难度。先调整范围，再评估是否需要额外行动成本；首版不附带伤害、属性扣减或随机失败。

## 后续实现验收清单

定向测试入口：「定向测试 → 月光照进来的时候 → 新物品 · 回声线轴」。首位人物携带线轴，留下线头后可走到相邻房间并尝试回返。现已覆盖取消确认、保存恢复、转交保留标记、停止移动、零移动力、过期确认及目的地敌方捕兽夹。下列其他边界仍需继续验证和完善。

另可选择「新物品 · 回声线轴（跳过陷阱）」，测试回返不触发中途陷阱，也不带走同行人物或消耗其他行动资源。

- 设置一次、取消不计次、不可远程设置或重新设置；同回合离开后可回返。
- 1步和4步允许，5步、同室、不可达及失效目标拒绝；正确计算跨层、单向通路和搬移房间。
- 已停止移动拒绝回返，单纯移动力为0允许；不占用或恢复其他行动机会。
- 无沿途效果；目的地入场效果按顺序结算一次，不重复抽取发现牌。
- 传送只作用于使用者，保留原有任务物品限制；交易、丢弃、拾取及阵营变化不重置标记。
- 消耗与落位一并提交，抵达流程可保存恢复；重复或过期确认不重复消耗、传送或结算入场效果。
- 联机只能由当前人物所属玩家操作，主机校验范围、归属和标记状态；公开标记不暴露隐藏陷阱。
- 验证旧剧本目标互动、血月追猎与目的地陷阱、蒸汽，以及神秘电梯搬移后的回返。
