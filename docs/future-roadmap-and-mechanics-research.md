# 预兆之屋：后续规划与机制调研

记录日期：2026-09-07。状态：未来规划与研究笔记，尚未实现；具体数值需要试玩验证。

## 1. 已确认的产品方向

- 正式玩法从探索开始，每局过程中触发不同剧本，不在大厅直接选择最终剧本。现有三个原创剧本作为第一批内容池；指定剧本入口可留在测试模式。
- 参考“预兆牌＋触发房间”的组合形式，并做原创扩展，让本局走过的房间、得到的物品和经历的事件共同影响故事。
- 房屋具有随机性和空间规则：抽房间、旋转、门对门拼接、多楼层、特殊移动、放置限制，以及在特定剧情中生效的窗户。
- 扩展物品落地、拾取、交换、抢夺、伙伴运送；加入改变掷骰、精神攻击、被困和救援等机制。
- 制作有自身特点的原创物品、事件、预兆、房间和人物，逐步让素材室支持真正可运行的 DIY 内容。
- 保持地图主导布局、可折叠状态窗口；沿用单人试玩与局域网联机方向。

本次只记录规划和检索结果，不改变现有 Demo 的玩法。

## 2. 先分清第二版和第三版

| 问题 | 第二版 | 第三版 |
| --- | --- | --- |
| 最终剧本如何确定 | 触发预兆＋所在房间查表 | 开局缘由卡（Scenario card）＋触发预兆 |
| 何时作祟 | 固定投 6 骰，结果小于累计预兆数 | 按累计预兆数投骰，达到 5；最后一张预兆保证触发 |
| 地下室开局是否存在 | 已摆出地下室起始块 | 同样有地下室起始块 |
| 抢夺是否通用 | 有：满足攻击差值条件后替代伤害 | 取消通用抢夺，由具体剧情另行授予 |

依据：第二版规则“Making a Haunt Roll / Revealing the Haunt / Setup / Special Attacks”；第三版规则第 5、7、10、14 页。[S1][S2]

**我们采用的是原创混合规则，不是逐条复刻某一版。** 美术参考第三版，不代表必须采用第三版的全部规则。用户提出的组合触发更接近第二版；第三版的“为什么来到这里”可作为叙事补充。

“地下室不存在”更适合解释为“还不知道如何进入、尚未探索”。界面可以先隐藏地下室地图，首次进入时揭示；底层仍可预留起始锚点，避免跨层事件没有落点。

## 3. 针对所提机制的检索结果

以下分为“规则书确认”和“社区组件资料线索”。后者可用于设计参考，但具体卡面、印次和数值仍需在制作对应内容前复核，不能直接当作官方裁定。

### 3.1 房间和空间

| 机制 | 找到的对应设计与证据 | 我们可以怎样使用（原创建议） |
| --- | --- | --- |
| 神秘电梯 Mystic Elevator | 二版规则确认：房间块本身移动，投骰决定楼层；三版社区房间表也有此牌。[S1][S4] | 实现“会搬家的房间”，让乘员、地上物品、房间标记随之移动；移动前显示落点，落地后更新路径。 |
| 坍塌房间 Collapsed Room | 二版有首次发现检定、坠入地下室和落点标记；三版社区记录改为回合结束时检定，失败去地下室起始块。[S3][S4] | 拆分“脚下塌陷”“下层落点”“后续可用通路”，以地图动画呈现，而不只扣属性。 |
| 滑道和回程楼梯 | 二版 Coal Chute 通往地下室；Stairs from Basement 需要探索发现才连接门厅。三版社区房间表列有 Laundry Chute。[S3][S4] | 下去容易、回来要探索；救援、寻找出口和跨层运送形成短期任务。 |
| 任意房间 | 暂不能唯一对应一张牌。三版 Map 物品有移动到任意已放置板块的效果；多楼层适用房间则是另一概念。[S5] | 分开设计“任意已探索目的地”和“允许多个楼层放置”，两者均不允许无条件抽取任意房间。 |
| 窗户 | 二版生存手册的特殊逃生规则使用朝外窗户，例如玩具飞机逃生；并非普通移动通道。[S6] | 窗户记录朝向及外侧是否被房间挡住；只有剧情或道具启用翻窗、透光、飞行逃生等动作。 |
| 放置限制 | 二版入口需接门，其他边可能形成封闭门；二、三版均要求避免封死本层继续探索的出口。[S1][S2] | 拼接预览直接显示合法旋转、堵门和禁放原因。特殊放置规则优先级明确，不把窗户当门。 |
| 房间内部障碍 | 二版 Chasm、Catacombs、Vault、Tower 等有跨越障碍规则。[S3] | 房间可划为两侧；人物所在侧影响可走的门与能否交互，避免视觉上隔着深坑却能交换物品。 |

**实现边界建议：** 电梯移动必须处理原位置断路、落点占用、无合法落点、重复进入和乘员同步。普通房间不能因一次旋转把玩家全部锁死；但剧情明确允许的断路应保留，并配套可执行的逃生手段。

### 3.2 事件、物品与伙伴

| 机制 | 找到的对应设计与证据 | 我们可以怎样使用（原创建议） |
| --- | --- | --- |
| 被碎物压住 | Debris 确实是二版事件，规则书提及其持续阻碍；社区摘要描述被困与脱困检定。它不同于坍塌房间。[S1][S7] | 做“被困—自救—队友救援”的持续状态；地图显示受困人物，不能只弹一次伤害就结束。 |
| 神秘滑道事件 | Mystic Slide 作为二版组件可查到；详细落点规则仍需核对卡面。[S7] | 事件可以在已有房间留下通路标记，使房屋在探索后继续变化。 |
| 改变骰子 | 二版 Lucky Stone 有一次性重掷线索；三版 Rabbit’s Foot、Lucky Coin、Creepy Doll 分别涉及单骰重掷、空白骰重掷附风险、整组重掷附代价。[S8][S5] | 将“增加骰数、修改单骰、重掷、替换总结果”分开；保留掷骰后的道具使用窗口。 |
| “神识”攻击 | 对应 Sanity（本项目称“理智”）较贴切。二版 Ring 与理智攻击有关，官方生存手册也有戒指攻击恶魔的剧情规则。[S9][S6] | 让理智型角色有攻击路线；攻击属性、防御属性、伤害类型各自声明，目标不适用时提前说明。 |
| 物品放地上、交换 | 二版有地上物品堆、拾取与同室交付规则；部分预兆伙伴不能按普通物品转交。[S3] | 每件道具有唯一位置：人物、房间或伙伴；从地图点物品堆即可查看和拾取。 |
| 抢夺 | 二版攻击本可造成至少 2 点肉体伤害时，可改取可交易物品或预兆；三版仅特定规则授予。[S1][S2] | 在允许抢夺时，战前声明或战后选择的时机需统一；推荐战后展示“造成伤害 / 抢夺一件”。剧情绑定物除外。 |
| 猎犬运送 | 二版 Dog 卡的公开转录：可往返六步以内的已探索房间，运一件物品；受通路限制，不能代替人物探索。[S10] | 地图预览往返路径和收件人；首版只做运送，不叠加独立战斗与复杂伙伴 AI。 |

“被压塌”目前保留两个候选：**Debris 的被困**与 **Collapsed Room 的坠落**。不把口头描述直接锁定成某一张卡；两个机制都值得进入素材设计池。

### 3.3 额外值得参考的设计

三版社区物品表还记录了几类变化：Magic Camera 改用理智完成知识检定；Skeleton Key 穿墙但不能探索；Mystical Stopwatch 增加行动回合；Angel’s Feather 替换检定结果。[S5] 这些是组件级线索，表中也混有扩展内容，不能把整表数量当基础版牌数。

本项目可据此探索：

- **能力转换而非只加数值：** 让人物以擅长属性应对少量特定问题，但不完全消除弱点。
- **付代价获得确定性：** 把“这次能不能赌赢”变成“值不值得耗掉道具”。
- **空间工具：** 临时穿墙、跨层绳索、标记传送点会使已有地图产生新用途。
- **时间资源：** 额外行动很强，应限定用途、次数和剧情阶段，不能通过转交无限重复。
- **特殊阵营和结局：** 三版规则区分无叛徒、单叛徒、隐藏叛徒、各自为战。[S2] 我们可先稳定合作与公开对抗，再扩展隐藏阵营。

第三版官方《Traitor’s Tome》中还能找到“家具成为敌人”“洪水改变房间状态”“怪物借带预兆图标的房间移动”等设计。[S11] 对本项目的启发是：**同一张地图在作祟后获得新含义**，剧情不必仅是更换敌人名称和血量。

## 4. 原创剧本触发方案

本节为提案，尚未定稿。

### 4.1 首版：预兆标签＋房间标签

正式流程：选择人物／可选入屋缘由 → 自由探索 → 抽到预兆并结算 → 作祟检定 → 用当次预兆和抽取时的房间匹配剧本 → 揭示阵营、目标和地图变化。

不要依赖几十个固定中文牌名硬编码。为房间与预兆设置少量主题标签，例如“回声、镜像、水、祭仪、机械”。匹配采用明确规则，保存触发时的房间快照，避免预兆效果先移动人物后查错房间。

| 现有原创剧本 | 候选触发组合（示意，并非已有牌面） | 揭示时的地图变化提案 |
| --- | --- | --- |
| 第十三声钟响 | 回声类预兆＋仪式／钟声房间 | 已探索房间出现共鸣点；钟声沿连通路径传播。 |
| 镜中来客 | 镜像类预兆＋镜面／卧室房间 | 房间出现真假映像与镜面通路。 |
| 深水之下 | 水类预兆＋潮湿／地下设施房间 | 低处出现积水，设备房成为关键位置。 |

同一预兆在不同房间应有不同结果；同一剧本允许多条触发路径，避免某一张牌没抽到就永远不会出现。初期只有三个剧本，允许多个组合汇入同一故事。

### 4.2 后续：经历参与，但保持可解释

可加入入屋缘由、已经打开的禁忌物、救过谁、是否破窗等少量条件。先筛掉无法完成的剧情，再在合格候选中匹配；若使用权重随机，权重规则固定，结果由主机生成并保存。通关后可解释“哪张预兆、哪个房间、哪些经历引出了本次故事”。

必须提供兜底：没有匹配、关键房间缺失、关键人物死亡、道具已经消耗、素材包禁用某个剧本时，都要能合法继续。补放任务房间应有明确剧情理由和合法落点，不凭空把目标塞到不可达处。

不要在前期公开最终剧本名称；可以展示逐步累积的声音、潮湿、倒影等线索。提前铺垫应有多种可能解释，保留揭晓感。

## 5. 原创素材种子

下面全部为本项目新提案，不是原作卡牌翻译；名称和效果均可修改，数值待测。

| 类型／名称 | 核心选择与效果草案 | 限制或代价 |
| --- | --- | --- |
| 物品：借运铜钱 | 掷骰后重掷选定的一枚骰子，把“不幸”留在当前房间。 | 下一位进入者触发轻度风险；禁止用于作祟检定，避免轻易挑选剧情。 |
| 物品：缝影针 | 以理智对抗敌人的理智；成功使其暂时不能离开房间。 | 替代普通攻击，不同时造成全部伤害；无理智目标不可用。 |
| 物品：旧邮差包 | 把一件道具封装，交由伙伴或玩家运送，到达后由收件人打开。 | 运送中不能使用；任务物是否可封装由剧情声明。 |
| 事件：墙后求救 | 可花行动拆墙救人，也可离开；选择会留下剧情标签。 | 救援不保证立即获得奖励，但不会靠隐藏必败选项惩罚玩家。 |
| 事件：楼板呻吟 | 本轮末房间将坍塌，可撤离、支撑或冒险取物。 | 提前在地图显示危险倒计时，让玩家能作决定。 |
| 事件：名字被叫走 | 玩家选择暂时失去一项道具能力，或承受精神风险以保留它。 | 持续时间和恢复条件始终可见。 |
| 房间：失层电梯 | 房间连同乘员移动，部分结果允许选择楼层。 | 只能落到合法入口；保留一次使用限制。 |
| 房间：倒悬书房 | 从上层进入后可能落入地下侧室，留下可研究的返回机关。 | 有自救与队友救援两条路线，不能无限困住低知识人物。 |
| 房间：雨窗长廊 | 窗户朝外时可观察天气；特定剧情中用于引雷或逃生。 | 相邻新房间可能遮住窗户，拼接前明确预览影响。 |
| 人物：旧宅测绘员 | 擅长判断特殊房间的落点或一次调整待放房间的选择。 | 不允许无限翻看牌堆；不直接知道未探索地图。 |
| 人物：夜班护工 | 擅长救援被困队友、把伤害转化为短期行动代价。 | 每轮限次，不能消除全部风险。 |

人物应同时有优势、弱项、属性轨形状和可影响故事的背景标签；首批每人只加一个容易理解的特长。伙伴另建类别，避免把猎犬等同于可随意丢弃的普通物品。

## 6. 建设顺序与完成标准

| 阶段 | 内容 | 完成标准 |
| --- | --- | --- |
| P0 剧情入口 | 将现有三个剧本接入组合触发；保留测试直达；增加揭示流程。 | 正式开局不选最终剧本；组合与兜底可复现；任务都可完成。 |
| P1 房屋规则 | 坠落、回程阶梯、电梯、合法拼接、单向与双向连接。 | 有可试玩的地下室脱困闭环；移动后乘员与标记位置一致；无合法位置时有清晰处理。 |
| P2 道具流转 | 落地、拾取、交换、抢夺、伙伴运送。 | 任一道具只在一个位置；刷新、重连、重复点击不会复制或丢失道具。 |
| P3 检定与状态 | 重掷窗口、精神攻击、被困与救援、跨回合事件。 | 双方都能用自己的道具；结果确认前不扣伤害；自动投骰不会跳过道具决策。 |
| P4 地图剧情 | 窗户、内部障碍、积水／燃烧等房间状态。 | 地图直观展示通行和目标变化；同一场景的特殊规则有可查询入口。 |
| P5 可运行 DIY | 素材定义、校验、内容包启用、剧本依赖检查。 | 编辑后的内容可开新局验证；错误指出具体字段；存档绑定内容包版本。 |

联机与每阶段同步推进：由主机裁定抽牌、移动、道具归属、随机结果和行动顺序；客户端提交意图。隐藏剧本、牌序和阵营秘密需要按玩家发送，不能只靠界面隐藏。支持断线恢复后继续待投骰／待救援／待交易，不重复结算。

单人控制全队无法获得与真人隐藏叛徒完全相同的信息体验。首版保留电脑对手；隐藏阵营剧情待联机信息隔离完善后再加入。

### DIY 数据需要表达什么

- 房间：可用楼层、门窗朝向、内部区域、放置约束、进入／离开／回合末效果、主题标签。
- 连接：门、楼梯、坠落、通道各自的方向、消耗、使用者限制和目的地。
- 卡牌：触发时机、目标、消耗次数、是否可交易／抢夺／运送、效果与恢复条件。
- 检定：基础属性、骰子数量、可修改阶段、修改优先级、终值与后果；区分直接降属性和受到伤害。
- 剧情：候选条件、必需素材、初始化、公开信息、阵营私密目标、胜负判定和缺件兜底。
- 标记：绑定房间／人物／连接／物品，而非只有一张图；房间移动时明确是否跟随。

## 7. 资料范围与待核对事项

本次找到了二、三版规则文本、官方剧情手册，以及部分公开组件目录／转录；**没有确认一套完整、官方公开、可直接导入的二、三版全部卡面图库**。

二版 BGG 房间表下载条目可作为下一轮逐张核对入口；本次只定位了条目，未读取其表格文件。[S12] 三版社区房间表含扩展角色注记，物品表也含扩展牌；不能直接整表导入并标成基础版。[S4][S5]

待核对：用户记忆中的“任意房间”具体对应对象；Debris 等事件的完整卡面与印次；二、三版同名物品是否改写效果；三版窗户在具体剧情中的用途。Widow’s Walk、Legacy、Baldur’s Gate 和自制剧情不混入基础版事实。

下一次实现建议从 **组合触发＋坠落地下室并找路回来** 开始。这两项最直接改变每局故事与地图探索体验；道具流转随后为救援、抢夺和猎犬建立基础。
