# 新物品牌设计登记

记录日期：2026-10-29。以下为原创物品牌设计，除特别标注已实现的内容外，均尚未实现；数值和未确认的规则需进一步讨论及试玩。故事文案为草案。回声线轴另见[独立设计稿](echo-spool-design.md)。

## 破旧的锁

*钥匙上还挂着写有房间号的纸牌，字迹却早已被刮掉。*

**已讨论效果：**一次性安装。持有者在自己的回合，选择当前房间一扇已经双向接通的门并上锁。锁住门的两侧，持有对应物品牌的人可以正常通过，经过后门仍保持上锁；其他人物和怪物想通过，须先尝试打破锁。

力量检定暂定为 **4+**：成功则锁被打破、永久失效，之后所有人可以通过；失败受到1点身体伤害，且该角色本回合不能再次尝试。其他角色仍可尝试，失败的角色下次自己的回合也可再试。怪物也可以尝试破锁。

安装后，在地图上留下锁标记，物品牌留在持有者手中代表钥匙。持有者可将牌交给其他人，持有牌的人获得通过权限。安装次数不因交付而重置。

**待确认：**尝试是否消耗行动或移动力、怪物的伤害结算、门的方向和跨层连接，以及锁破坏后钥匙牌如何处理。

**开发进度：**已接入上锁、地图标记、钥匙转交及力量4+破锁。人物或怪物破锁失败受到1点身体伤害，本回合不能再次尝试同一把锁；固定属性怪物因此击晕，属性轨怪物扣除身体属性。试玩时暂定破锁不消耗互动或移动力，锁打破后钥匙牌保留但不能重新安装。人物普通移动和回声线轴会检查通行权限；物品加入通用扩展游戏集。

**测试入口：**「定向测试 → 月光照进来的时候 → 新物品 · 破旧的锁」。首位人物先锁住通往门外怪物所在房间的门；可以将锁牌交给同室队友，随后选择破锁，也可以结束本轮观察怪物破锁。

「新物品 · 破旧的锁（怪物钥匙）」可验证人物转化为怪物后仍持有钥匙时，无需破锁即可通过，门继续保持上锁。

## 现有恢复物品调整

以下记录已实现的恢复物品和后续候选。

- **急救箱（已实现）：**一次性，将最多4格恢复自由分配到自己的力量和速度，最多恢复到起始位置；受其他属性上限限制时同样不能超过上限。可恢复的格数不足4格时，分配全部可恢复格数。能否用于同室人物待确认。
- **止血绷带：**只保留一张，不增加同名牌。现有效果为一次性恢复力量或速度2格；未来通过其他不同物品增加身体恢复机会，而不是复制绷带。
- **恢复上限：**恢复效果同时受起始位置和当前属性上限限制；已经达到可恢复上限时不能消耗恢复物品。可在「定向测试 → 月光照进来的时候 → 恢复物品 · 属性上限」验证。
- **运动饮料：**一次性，从饮用的当前回合开始，连续两次在自己的回合结束时，选择恢复1格力量或速度，不超过对应属性的起始位置或当前上限。两项均已满时该次恢复失效，仍消耗一次持续回合。测试入口：「定向测试 → 月光照进来的时候 → 恢复物品 · 运动饮料」。
- **清醒盐（原安神药）：**一次性恢复自己2格知识，最多到起始位置。原卡牌 ID `tonic` 保留。
- **褪色茶包（原宁神茶）：**一次性恢复自己2格理智，最多到起始位置。原卡牌 ID `tea` 保留。这两张牌的名称和区分方式为当前试玩方案，可继续调整。

可供讨论的差异化恢复物品草案：

| 候选物品 | 作用提案 | 定位 |
| --- | --- | --- |
| 肌肉喷雾 | 一次性，自身速度恢复2格，最多到起始位置。 | 有针对性的身体恢复。 |
| 随身药箱 | 一次性，为同室另一名人物恢复力量或速度2格，最多到起始位置。 | 帮助同伴，与急救箱的自用定位区分；急救箱目标仍待确认。 |
| 怀旧音乐盒 | 一次性，自身理智恢复1格，且下一次受到精神伤害时减少1点。 | 恢复较少，但带一次防护；防护持续时间待定。 |

表中其余名称、数值和效果只是待讨论提案。

**测试入口：**「定向测试 → 月光照进来的时候 → 恢复物品 · 清醒盐与褪色茶包」，首位人物的知识和理智均已受损。

## 知识面包

*面包上印着密密麻麻的字，咬过的地方却一片空白。*

**已实现：**一次性食用，力量提升1格，知识提升2格，最多到各自属性轨上限。纳入通用扩展游戏集，经典游戏集不变。

**定向测试：**首页选择「定向测试 → 月光照进来的时候 → 新物品 · 知识面包」，确认开局提示后从首位人物背包食用。急救箱另选「新物品 · 急救箱自由分配」，从背包选择力量与速度的恢复组合；可保存测试点并反复验证。两个入口复用原狼人测试地图，并非新的狼人规则。

## 后续讨论的物品

除标注已实现的项目外，以下规则尚未实现。具体使用时机、作用范围和与其他效果的关系需在开发时补齐。

- **生存指南（已实现）：**获得时知识提升1格，知识检定多投1枚骰；交付、放下或失去时知识下降1格，最低保留骷髅前一格。拾取或受让时由新持有者提升1格；提升不超过属性上限。在「定向测试 → 月光照进来的时候 → 新物品 · 生存指南」可验证交付和拾取。
- **旧八音盒（已实现）：**每轮一次，持有者进行知识4+检定，成功后可选择最多两名存活人物（包括自己，不限距离），各恢复1格理智，最多到起始位置。失败或放弃恢复都消耗本轮演奏机会，物品不销毁。转交不会重置该轮次数。此处沿用讨论中提出的4+与每轮一次，尚需试玩确认。在「定向测试 → 月光照进来的时候 → 新物品 · 旧八音盒」可验证。
- **荆棘铠甲（已实现）：**每次受到同室敌人近战攻击并实际承受身体伤害后，可选择让攻击者承受1点身体伤害；无每轮次数限制。当前支持敌方人物、旧生命值怪物、固定属性怪物和属性轨怪物。持有者死亡后不再触发。在「定向测试 → 月光照进来的时候 → 新物品 · 荆棘铠甲」可验证。

  另有「新物品 · 荆棘铠甲（属性轨反伤）」测试点，可验证反伤达到怪物特殊消灭条件后的胜利结算。
- **沉重铠甲（已实现）：**持有时每次受到身体伤害减少1点，每回合初始移动力减少1点，最低为0；不影响精神伤害。包含银弹在内的身体伤害均适用，效果随物品交付变化。在「定向测试 → 月光照进来的时候 → 新物品 · 沉重铠甲」可验证。
- **幽影斗篷（已实现）：**攻击命中时可选择进行速度4+检定，成功则闪避该次攻击及其附带效果。支持哀鸣小提琴、普通手枪、人物近战、怪物攻击与反击及咬痕卡牌攻击；闪避可避免冰霜刃减速和狼人攻击附带的感染。手枪本身的闪避失败后才能使用斗篷；银弹沿用无法闪避的规则。纳入通用扩展游戏集，经典游戏集不变；检定门槛和使用次数仍需试玩确认。可在「定向测试 → 月光照进来的时候」选择「新物品 · 幽影斗篷」的范围攻击、手枪、近战、怪物攻击、怪物反击或卡牌攻击测试。
- **哀鸣小提琴（已实现）：**作祟期使用，选择任意已探索房间，当前试玩不限制距离、连通和楼层；该房间内所有人物受到1点理智伤害，所有怪物受到1点精神伤害，不区分敌我，选中自己所在房间时自己也受影响。使用占本回合唯一一次攻击。精神免疫怪物不受影响；固定属性怪物击晕，属性轨怪物扣理智。旧模型怪物受此伤害时暂以击晕处理，不扣生命值。范围和伤害数值仍需试玩。

  定向测试入口：「定向测试 → 月光照进来的时候 → 新物品 · 哀鸣小提琴」，选择门厅可观察队友、固定属性怪物、精神免疫怪物和属性轨怪物的结算。
- **应急口粮、肾上腺素针和前人的笔记：**仍为上轮恢复物品候选，名称和数值未逐项确定；用户提到书本可使用「生存指南」，故不能假定前人的笔记已获认可。

## 怪物机制方向

所有怪物具备力量、速度、理智、知识四项属性。普通怪物大部分采用固定属性：普通伤害使其击晕、跳过下一次怪物回合，不扣属性，也不使用生命值；满足怪物或剧本指定的特殊条件才能永久消灭。特殊怪物可拥有像英雄一样能升降的属性轨。部分怪物不受精神影响；免疫范围、击晕重复叠加和属性轨怪物的死亡条件仍需具体确定。

原有剧本作为测试用途，尚未进行正式内容优化；现有生命值敌人及其胜负条件需要迁移到新机制，并提供适合测试的消灭条件。

**基础测试入口：**「定向测试 → 月光照进来的时候 → 怪物机制 · 固定属性与击晕」。测试怪物与首位人物同室，普通攻击命中后会击晕；结束所有人物行动后，该怪物跳过一次怪物回合并恢复。也可趁怪物被击晕时在同室使用一次互动永久封印，验证特定消灭条件。

「怪物机制 · 陷阱击晕」和「怪物机制 · 陷阱与蒸汽」可测试怪物进入人物所在房间后被击晕，仍结算该房间的其他效果，但不再攻击，并保留击晕直到下一怪物回合。

**属性轨测试入口：**「定向测试 → 月光照进来的时候 → 怪物机制 · 属性轨怪物」。该测试怪物有四条可升降属性轨，近战、枪击和环境伤害会扣减对应属性；自动控制的怪物优先从剩余可扣格数较多的属性分配伤害。默认最低保留死亡点前一格，超出的伤害失效；本测试怪物另设任一属性降至死亡点即消灭的特殊条件，并非所有怪物的通用规则。规则效果可以调整属性，也可以造成精神伤害；标记精神免疫的怪物不受精神伤害，其他精神效果须明确标记才能应用免疫，精神效果不能改变其任何属性。可通过「怪物机制 · 属性轨精神免疫」测试小提琴与身体攻击。

「怪物机制 · 属性轨狼王」可验证属性轨怪物不会继承旧生命值狼王的厚皮伤害上限；旧存档的生命值狼王仍沿用旧规则。

旧测试剧本中的守钟人、镜魇真身、游荡倒影、溺亡者、钟声幽影和狼人已迁移为固定四属性怪物：普通伤害使其击晕，击晕后可在同室消耗互动封印。封印是供旧剧本测试的临时特殊消灭方式，不代表剧本内容已经优化；封印守钟人或狼人时，其对应的叛变人物也被消灭，封印镜魇或全部狼人则完成相应剧本。固定属性的旧狼人没有生命值再生和厚皮减伤，但保留月光力量加值及月印解咒路线。已有旧存档中的原怪物暂保留生命值模型及旧结算。

**旧剧本测试入口：**「定向测试 → 第十三声钟响、镜中来客或深水之下 → 怪物机制 · 旧剧本怪物」，首位人物与怪物同室，可直接验证击晕与封印。镜魇真身和旧狼人另有各自的定向测试点。

## 冰霜刃

*剑刃上凝着霜。握住它时，你听见冰层下有什么东西在呼吸。*

**效果提案：**近战攻击获胜时，可选择少造成1点伤害，使目标下一次自己的回合移动力减少2点。

**已实现的试玩细节：**主动近战获胜后可选择少造成1点伤害，令目标下一次自己的回合初始移动力减少2点，最低为0。效果适用于人物及固定、属性轨和旧模型怪物；多次减速不叠加，刷新为一次减速。被击晕的怪物在跳过回合时也消耗该次减速。伤害差为1时可选择不造成伤害并减速。已加入通用扩展游戏集。

**测试入口：**「定向测试 → 月光照进来的时候 → 新物品 · 冰霜刃」。与同室测试怪物近战，获胜后选择是否减速。

## 邪恶小刀

*刀身上刻着一行小字：再近一点。*

**效果提案：**主动近战攻击前，可选择多投2枚骰；若本次攻击未获胜，自己承受1点精神伤害。

**已实现的试玩细节：**主动近战掷骰前选择是否使用，加2枚攻击骰；平局和战败都视为未获胜。战败时先结算身体反击，再结算小刀的1点精神伤害；该伤害可被精神防具减少。小刀不会因使用而损毁。支持对怪物和人物的主动近战，并可与冰霜刃配合。已加入通用扩展游戏集。

**测试入口：**「定向测试 → 月光照进来的时候 → 新物品 · 邪恶小刀」。攻击同室测试怪物，在掷骰前选择是否使用小刀。

## 驱邪手铃

*铃声停下后，房间里的回音还在向远处退去。*

**已讨论效果：**可使用两次；选择与持有者同室或位于相邻房间的角色，将其移动最多3格。

**已实现的试玩细节：**持有者在自己的回合选择人物或可见怪物；相邻房间须有双向接通的门。由持有者逐格选择方向，可提前结束，经过房间正常结算入场效果。强制移动不消耗或恢复目标移动力，人物已停止移动也可被移动；锁门仍限制通行，触发捕兽夹或怪物受阻时停止继续移动。未移动则不消耗次数，两次用完后销毁。已加入通用扩展游戏集。

**测试入口：**「定向测试 → 月光照进来的时候 → 新物品 · 驱邪手铃」。首位人物携带手铃，队友同室、测试怪物在相邻门厅。

「新物品 · 驱邪手铃（蒸汽）」可测试人物被移动进入蒸汽后，检定失败会结束本次强制移动；原本已停止移动的人物仍可成为手铃目标。

## 厚皮围裙

*皮面上的旧刀痕很深，却没有一道穿透。*

**效果提案：**每轮首次受到身体伤害时，可选择减少1点。

**状态：**名称和效果均为候选，减伤时机及叠加方式待确认。

## 心灵护符

*它贴着胸口时，你总觉得有另一颗心在跳动。*

**已讨论效果：**每轮首次受到精神伤害时，可选择减少1点。受到致命伤害时，无论身体或精神伤害，可选择使用护符保命：照常分配并承受伤害，但相关属性最低保留在死亡点前一格，无法继续扣除的伤害失效。结算后护符损毁。

例如一条属性距死亡点还有2格，向其分配3点伤害时，使用护符后下降1格，停在死亡点前；分配给其他属性的伤害仍正常结算。

**已实现的试玩细节：**每轮第一次精神伤害时可以选择减1点，放弃也用掉本轮机会；随后若仍为致命伤，可以另选是否销毁护符保命。保护覆盖该次伤害的全部分配，逐点分配时也持续生效；其他属性正常下降，无法安全承受的部分失效。暂只处理由身体或精神伤害导致属性降至死亡点的情况。

**测试入口：**「定向测试 → 月光照进来的时候 → 新物品 · 心灵护符」。先选择是否减少精神伤害，再把伤害分配给已处于死亡点前一格的理智，观察保命选择。

## 防暴盾

*盾面上满是凹痕，背后的握把却被擦得很亮。*

**已讨论效果：**同室角色受到超过1点身体伤害时，持有者可选择让防暴盾承受超过1点的部分。受伤角色至少承受1点；盾牌承受的伤害累计消耗其耐久，耗尽后损坏。超过剩余耐久的伤害仍由受伤角色承受。

例如受到3点伤害时，可由角色承受1点、盾牌承受2点。

**已实现的试玩细节：**耐久暂定4点；持有者自己也可以受保护。先计算沉重铠甲等固定减伤，再由持盾者选择承受多少点，至少留下1点给目标；持盾者可以放弃。剩余耐久会在物品详情中显示，转交时保留。

**测试入口：**「定向测试 → 月光照进来的时候 → 新物品 · 防暴盾」。结束本轮，敌人攻击造成超过1点身体伤害时会出现防护选择。

## 替身木偶

*它穿着和你一样的衣服，胸口有一道新缝上的裂口。*

**已讨论效果：**一次性。发生一次身体伤害时，可将这次伤害转移给任意一名人物，但不能选择攻击者或伤害来源；目标不能拒绝。转移的伤害不致死，超出目标安全承受空间的部分失效，使用后木偶销毁。

例如转移4点伤害，目标只能安全承受2点时，目标承受2点，其余2点失效。

**已实现的试玩细节：**持有者转移自己受到的身体伤害；目标为除自己和伤害来源外的存活人物，不限距离，目标负责分配且不能拒绝。先计算原受伤者的固定减伤，再转移剩余伤害；目标的防具仍可生效。转移伤害不能使属性进入死亡点，不触发心灵护符的致命保护。木偶消耗后不能再次转移同一次伤害。

**测试入口：**「定向测试 → 月光照进来的时候 → 新物品 · 替身木偶」。首位人物即将承受4点身体伤害，可转移给队友；该队友仅有2格安全空间。另选「新物品 · 替身木偶（狼人目标）」可验证向不是伤害来源的狼人角色转移伤害，以及不致死限制。

「新物品 · 替身木偶（枪击来源）」可验证普通枪击命中后不能将伤害转移给射击者。

## 改运骰盅

*骰子落定后，盅里还有一声轻响。*

**效果：**一次性。自己的事件检定失败后，可重掷本次全部骰子，必须接受新结果；使用后销毁。

**已实现的试玩细节：**仅在自己的事件检定失败时出现，可放弃并保留骰盅；使用后重掷全部骰子并销毁。命运戒指先结算，再按当前结果判断能否使用骰盅；骰盅重掷后直接接受新结果。已加入通用扩展游戏集。

**测试入口：**「定向测试 → 月光照进来的时候 → 新物品 · 改运骰盅」。打开事件卡并进行检定，失败后可选择重掷。

## 移形镜

*镜子很小，却同时映出了两个房间。*

**已讨论效果：**一次性。在自己的回合，选择同一楼层的另一名人物，与其交换位置，无视距离；使用后销毁。

**已实现的试玩细节：**不限制阵营，不连通的同楼层房间也可以交换，停止移动不阻止交换。由使用者确认，双方同时改变位置，再依次结算使用者、目标的入场效果，不重复抽取发现牌；取消或确认前条件失效时不消耗。纳入通用扩展游戏集。

**测试入口：**「定向测试 → 月光照进来的时候 → 新物品 · 移形镜」可测试友方交换；选择「新物品 · 移形镜（敌对人物）」可测试与同楼层狼人交换。
