# 试玩反馈修复 · 2026-09-08

## 界面与说明

- 移除房间边缘的“某某行动中”和“落位预览／已吸附”文字。当前人物以棋子亮环、左侧高亮和顶栏行动状态标记，房间放置仍在地图外的操作栏确认。
- 每组骰子右侧使用小型“投掷”按钮，保留动画、自动投掷、双方各投自己的骰子及结果确认。
- 人物属性实际结算后提示原值、新值及升降格数，同时高亮对应属性和人物卡。连续相同数值的轨道仍显示格数变化；刷新载入存档不会当作一次新的属性变化。
- 咖啡明确说明：只增加本轮剩余移动力，不能解除抽卡或休整造成的停止移动。停止移动时禁用饮用按钮；引擎也会拒绝消耗咖啡并提示下轮使用。
- 银色吊坠的基础效果与剧本效果分开：抽牌、随身物品、素材室中，只有狼人作祟已揭晓时显示带月光边框的额外治疗能力，探索阶段和其他剧本不显示。
- 右侧目标、手记与结束整轮按钮改为顺序排列，手记独立滚动。

## 剧本与存档

未复现定向狼人新局切换成镜中来客。新增测试覆盖镜片预兆触发、交互掷骰、保存恢复以及联机重连；定向狼人始终进入狼人，组合模式才按映射揭晓镜中来客。

已确认大厅存在混淆入口：选择新剧本不会改变“继续探索”所恢复的旧存档。现在按钮分别明确标注“继续旧局”和“新开一局”，附带各自的剧本及模式；对局顶栏与联机大厅也显示当前模式。没有修改或覆盖玩家的旧存档。

## 阵营与公开信息

左栏按探险队／好人、狼群、叛变者、怪物和已死亡分组。转化者只以一个怪物实体展示，显示原人物关联和当前怪物的公开数值；怪物死亡、人物死亡和解咒会更新分组。

已现身怪物和人物一样出现在对应楼层标签中，怪物的位置按钮可切换地图楼层。尚未现形的镜魇只显示未知条目，不展示真镜位置或数值。守钟人的移动与死亡同步到原人物，新旧存档均兼容。

联机狼方的界面不展示好人的随身物品与属性轨；房主代管的好人仍可查看。转化前物品与普通人物属性不会作为狼人能力展示。狼方追猎指令继续仅在所属座位显示。

这里实现的是界面展示边界，现有联机同步协议仍发送完整对局状态；本轮没有新增面向不可信客户端的秘密数据隔离。
