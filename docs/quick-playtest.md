# 快速作祟测试

## 单人入口

1. 展开大厅“定向试玩（测试入口）”，选择狼人或其他指定剧本；人数沿用大厅设置，默认 3 人。
2. 选择“测试场景”后点击“直接进入作祟”，确认一页作祟说明后即可行动。狼人支持作祟开局、狼毒治疗、即将转化和月印解咒，其他剧本提供作祟开局。
3. 需要重测时，点击右上角设置旁的“测试”展开工具后选择“重置当前场景”，或在右上角设置中选择“重置测试局”，回到同一场景、地图、狼王人选、牌堆和随机序列的开局；当前测试局后续操作会被清除。
4. 返回大厅可用“继续测试局”恢复进度；测试结束后的“再来一局”仍直接作祟，使用新的随机种子。

## 预置内容

- 11 间房，来自原有房间定义；一楼、二楼、地下室通过真实门与楼梯相通，全部目标可达。已铺房间从剩余房间牌堆移除，仍可继续探索。
- 首位人物携带浓缩咖啡、止血绷带、银色吊坠；按原有获得流程结算吊坠的理智提升，并从各自牌堆移除。
- 狼人基础测试从有月光的温室开始，人物与狼王同室，可以马上测试攻击、封窗。
- 跳过前期探索、抽牌确认与作祟检定，只保留一次正式作祟说明。作祟的阵营分配、人物属性、目标难度、敌人行动、倒计时和交互掷骰继续使用原规则。
- 基础场景不预先完成目标，其他场景按下表预置状态。它们不修改普通对局，也不能作为平衡胜率样本。

| 狼人测试场景 | 预置状态                                         | 可立即验证                             |
| ------------ | ------------------------------------------------ | -------------------------------------- |
| 作祟开局     | 满状态人物、月光房间、狼王同室                   | 战斗、封窗、月光强化                   |
| 狼毒治疗     | 两名好人感染三轮，首位人物携带吊坠且力量损失一格 | 自疗、同室治疗、吊坠加值、绷带恢复     |
| 即将转化     | 非当前行动者的一名好人感染剩一轮                 | 结束整轮后阵营变化，新生狼人当轮不追猎 |
| 月印解咒     | 两处月印完成，首位人物位于入口，一名队友仍感染   | 入口解咒、清除狼毒、好人胜利           |

## 保存与恢复测试点

单人点击右上角设置旁的“测试”展开悬浮工具窗，提供“保存测试点”和“回到测试点”。在准备尝试某一步之前保存，之后可反复恢复；会保留当时的地图、人物、行动消耗、事件队列、随机状态与已经投出的骰子。每次保存会替换唯一的测试点；只有同一剧本、人数、开局种子和测试场景才允许恢复，避免误载另一局。

掷骰、卡牌和伤害弹窗内也有折叠的“测试点工具”，可以保存部分投掷或尚未结算的步骤；伤害分配的未确认预览不属于已结算对局状态。恢复时重新挂载操作界面，不沿用恢复前的临时分配。胜负结算页可回到此前的测试点，结束状态下禁用保存，避免误覆盖有用的测试点。

测试点保存在 `hillhouse-haunt-checkpoint-v1`，与普通存档、测试自动存档分开。存储失败会明确提示。联机没有本地保存／回退测试点按钮。

## 存档与联机

普通存档使用 `hillhouse-demo-v2`，快速测试使用独立的 `hillhouse-haunt-playtest-v1`。进入或重置测试不会覆盖普通存档；“继续旧局”和“继续测试局”分别恢复各自进度。

联机时先选择指定剧本并创建房间，至少两位玩家加入后，房主可选择测试场景并点击“定向测试 · 直接进入作祟”。未知故事的组合模式不提供快速入口。主机验证场景必须属于所选剧本；仅房主能开始，其他玩家刷新后仍恢复同一对局。已开局不能再次开始或借此重置；单人顶栏重置功能不用于联机房间。

## 验证

快速测试包含 9 项自动测试，覆盖四个剧本、3–6 人、三个随机种子共 48 个基础开局的全图连通与目标可达，以及治疗、转化、解咒、测试点完整恢复与联机场景权限。当前完整测试 67 项通过，游戏代码静态检查、生产构建和离线打包通过。本轮未进行浏览器人工视觉验收。

地图、自动结算与动态卡牌的最新操作见 [动态卡牌与地图悬浮界面](dynamic-cards-and-map.md)。
