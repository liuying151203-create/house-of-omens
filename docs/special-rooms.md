# 神秘电梯与坍塌房间

2026-09-10。采用用户选定的二版基础，并适配当前三层地图和电脑敌人回合。

## 试玩入口

刷新本地试玩，右上角「测试」选择「神秘电梯」或「坍塌房间」。人物位于门厅，点击右侧对应房间即可进入；电梯需主动点击人物旁的「启动电梯」。可以保存测试点，保留房间、骰子及待选落点，反复尝试。新开普通游戏也会将两张房间加入牌堆；旧存档的牌序保持原样。

## 神秘电梯

- 进入后可主动点击人物旁的「启动电梯」投两枚骰；每名人物每轮只能启动一次。若新一轮仍在电梯内，可用人物旁的「启动电梯」。抽牌造成的停止移动期间不能再次启动。
- 0–1 点到地下室，2 点到一楼，3 点到二楼，4 点任选楼层。0 点时室内每名探险者另投一枚骰，分别分配肉体伤害。
- 地图亮起合法门口，点击更换停靠点，可旋转后确认。同一空格可接不同门口时，旋转会同步切换接入门，保留该落点所有合法朝向。目标楼层无合法位置时留在原地，仍消耗本轮使用机会。
- 保留房间身份，仅改变楼层、坐标和朝向，因此室内人物、怪物、物品标记、目标进度同步移动。旧位置的相邻门连接自然断开，落地后重新计算。
- 电脑敌人目前沿电梯所在位置的门通行，可随乘员搬移；不自主操纵电梯选层。这是当前电脑行动系统的适配范围。

## 坍塌房间

- 首次发现进行速度 5+ 检定，通过则留在房间；失败建立地下室落点。此后进入不再检定，可主动选择「跳入地下室」。
- 首次坠落从牌堆找可放置的普通地下室房间，在地图选择门口并旋转；房间留下「坍塌落点」标记。之后重复使用同一落点，不重复抽房间或卡牌。
- 坠落不额外消耗移动力，每次另投一枚骰决定肉体伤害。先分配伤害，再处理新落点的房间效果和抽牌；死亡人物不会继续领取卡牌。
- 探险者不能沿坍塌洞口反向攀爬。电脑怪物可沿已建立的洞口上下穿行，路线进入现有移动动画，仍只在敌人回合移动和攻击。
- 当前适配：首次落点不抽神秘电梯，避免嵌套搬移；没有可放置的地下室房间时以地下室平台兜底。在尚未连通楼梯时，可于地下室平台消耗一次正常移动成本寻找永久连接门厅的回程暗梯。

## 交互与验证

房间效果放在地图左上角的小图标，悬停或点击查看；跨层符号位于右下。停靠与坠落有落地动画，伤害进入探索手记。沿用现有投骰动画、停顿及自动结算。

覆盖检定结果、合法位置、乘员与房间标记同步、限次、首次与重复坠落、落点抽牌顺序、伤害死亡、地下室返回、敌人移动、存档恢复、联机权限以及普通牌堆探索。
