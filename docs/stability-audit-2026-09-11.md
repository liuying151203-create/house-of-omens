# 2026-09-11 核心流程稳定性检查

本轮暂停新增玩法，检查探索、切层、电梯、坍塌和敌人回合。以下区分浏览器实际操作与自动化验证，作为后续修改的回归清单。

## 本轮确认并修复

| 问题                             | 复现与修复结果                                                                                                                                                                         |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| “回到人物”无法切回人物楼层       | 人物在地下室、查看一楼时点击按钮，原来仍停在一楼。现在先切回人物所在楼层再定位，已在新版浏览器复验。                                                                                   |
| 切层往返恢复旧探索确认           | 首次点击门外只预览，切到别层再回来，原来仍显示“再次点击抽取”。现在切层、换人或位置变化会清除预览；新版实测恢复首次预览，牌堆数量未减少。                                               |
| 敌人伤害结算前恢复下一回合移动力 | 原来沈墨受伤速度 3→2，下一回合仍有 3 移动。现在敌人伤害、结果提示全部完成后才开始新回合。实测第一回合攻击 7 对 2，分配 3 点肉体伤害后，第二回合沈墨恢复 2 移动；伤害日志属于第一回合。 |
| 旧结束行动请求能误结束下一位人物 | 引擎测试复现同一请求重放会连续结束两人。界面请求现在带人物与回合，拒绝过期请求；另保护过期的结束整轮请求。                                                                             |

另外补上窄屏测试图标的无障碍名称。此前未提交的跨楼层探索校验、电梯每次消耗 1 点移动力且允许回合内重复启动，也保留在当前版本中。

## 浏览器实际走过的流程

- 神秘电梯：走入房间不会自动掷骰；点击启动后显示骰子动画，消耗 1 点移动力；同一落位格存在两个门口锚点时旋转能切换锚点；确认后乘员跟随房间，仍有移动力时继续显示启动入口；测试存档恢复后房间位置与乘员保持一致。
- 坍塌房间：首次进入速度检定成功后主动跳下，选择地下室新房间并确认；先投坠落伤害骰、分配伤害，再抽取落点房间的预兆；作祟阶段没有额外作祟检定。第二名人物进入已检定的坍塌房间不重复首次检定。
- 楼层与探索：地下室人物查看一楼时，一楼普通探索入口禁用；首次门外点击只预览；切到一楼后使用“回到人物”返回地下室，旧预览被清除。
- 狼人：最后一名好人结束行动后先显示敌人行动过程，再出现攻击、防御骰；投骰有翻滚过程，完成后自动进入伤害分配。新版本实测伤害结算完成后才刷新下一回合移动力，手记保留攻击点数和具体属性变化。

电梯连续多次启动直到移动力耗尽、无合法落点、多人冲击、存档中途恢复、重复请求等边界由自动化用例覆盖；本轮未在浏览器逐一手动遍历所有分支。联机规则执行了现有自动化测试，未进行多台设备实际联机验收。

## 后续修改的最小回归步骤

1. 从另一楼层观察当前人物，点击“回到人物”；预览探索后切层往返，确认仍需重新预览。
2. 神秘电梯在同回合连续启动，检查每次只扣操作者 1 移动，乘员和旋转锚点正确。
3. 坍塌首次检定、主动跳下、落点放置、伤害、抽卡按顺序完成；第二人进入不重复首次检定。
4. 狼人移动到同室才攻击；检查掷骰动画、伤害分配、日志回合，以及下一回合移动力与最终速度一致。
5. 涉及状态流程的修改执行全套测试；涉及界面入口的修改同时进行浏览器操作，不能仅以引擎测试代替界面验证。
