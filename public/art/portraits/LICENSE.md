# Character portrait attribution

Source: https://ladadori.itch.io/realistic-avatars-for-rpg

The author explicitly identifies the license as CC0 in the original release post:
https://www.reddit.com/r/gameassets/comments/kjb8fr/120_realistic_avatars_for_rpg_ethnic_gender_and/
The itch.io description contains the typographical spelling "CO0".

The author used Artbreeder and finished the images in Krita. These are synthetic
portraits, not photographs of the game's fictional characters.

Retrieved 2026-09-14. Selected original PNGs are unchanged. CSS applies a shared
frame, desaturation and brightness adjustment during display. The exact mapping
to original archive filenames is recorded in lib/portrait-art.json.
